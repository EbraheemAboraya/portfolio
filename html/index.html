FEATURED / DATA ENGINEERING

Amazon Data Lakehouse

From raw eCommerce events to analytics-ready data.

An end-to-end lakehouse processing 183,922 synthetic eCommerce records across five batch and streaming sources, including late-arriving orders, product dimensions, pricing history and reviews.

  • Bronze, Silver and Gold layers with Spark and Iceberg
  • Kafka streaming and Airflow batch and streaming DAGs
  • Dimensional facts, aggregates and session-conversion ML features
  • Cross-layer data-quality checks and an HTML business dashboard
  • Apache Spark
  • Kafka
  • Airflow
  • Iceberg
  • MinIO
  • Docker
Inside the project +

Pipeline design: Batch and streaming workflows handle late-arriving orders and preserve pricing history with SCD Type 2. The Gold layer prepares dimensional facts, aggregates and features for session-conversion machine learning.

Quality and traceability: Cross-layer validation produces Great Expectations-compatible reports, with DataHub lineage artifacts documenting the flow of data.

Delivery: Three service stacks run with Docker Compose, alongside MinIO storage and an HTML dashboard for business analysis.

Project context: Academic final project using synthetic eCommerce data.
